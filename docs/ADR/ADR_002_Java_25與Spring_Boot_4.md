# ADR_002 Java 25 與 Spring Boot 4

> 狀態：已接受
> 日期：2026-10-14

## 背景

需要決定語言版本與框架版本。專案會持續開發一段時間，並以高併發為練習重點。開發者目前的環境為 JDK 21。

## 考慮過的選項

| 選項 | 優點 | 缺點 |
|---|---|---|
| Java 21 | 已安裝；長期支援版本；生態系最成熟 | 虛擬執行緒遇到 `synchronized` 時會佔住底層執行緒，在高併發下可能耗盡執行緒 |
| Java 25 | 最新的長期支援版本；修正了上述虛擬執行緒的問題；支援期最長 | 需要另外安裝；少數工具對新版本的支援可能較晚 |

框架方面，Spring Boot 4 是目前的主要版本，Spring Modulith 等周邊專案的新版本都以它為基礎，沒有選擇舊版的理由。

## 決定

- 採用 Java 25
- 採用 Spring Boot 4，建立專案時以當時最新的穩定版本為準
- JDK 25 以壓縮檔安裝在 `D:\Programming\java\jdk\`，不改變系統的 `JAVA_HOME`；本專案以專案層級的設定指定 JDK，不影響其他使用 JDK 21 的專案

## 後果

- 好處：可以放心使用虛擬執行緒處理大量請求，並在壓測中比較虛擬執行緒與傳統執行緒池的差異
- 代價：需要維護兩個 JDK；若某個工具尚未支援 Java 25，需另找替代或暫時降版
- 重新檢討的條件：無，除非出現無法解決的相容性問題
