# 文件索引

## 資料夾結構

| 資料夾 | 內容 |
|---|---|
| `需求/` | 需求規格與使用者故事 |
| `設計/` | 領域模型、狀態圖與循序圖、系統架構、資料庫設計、API 規格、測試計畫 |
| `ADR/` | 架構決策紀錄 |
| `pdf/` | 定版文件轉出的 PDF，子資料夾與上面相同 |

Markdown 是文件的原始檔，修改一律改 Markdown；定版後以 `scripts/md2pdf.py` 轉出 PDF，PDF 不手動修改。各文件的目前版本記錄在文件開頭與文件末的版本紀錄。

OpenAPI 規格檔是程式的來源，放在各後端專案的 `src/main/resources/openapi/` 底下，不在本資料夾。

## 文件的命名與修改規則

- 檔名格式為「類別_編號_標題」，編號在同一類別內遞增
- 討論中的文件標為「草稿」；定版後標為「定版」並記錄版本
- 定版後的修改：升版、在版本紀錄中說明，並重新產生 PDF
- ADR 接受後不修改內容；決策改變時新增一份 ADR，並將舊的標為「已被取代」
